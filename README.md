# Dijital Çay Demleyici 🍵

## Giriş

Bu proje, insanlık tarihinin en büyük sorunlarından birini çözmek üzere tasarlanmıştır: **Doğru çay demleme süresi**.

Artık çayınızın acı olup olmadığını merak etmenize gerek yok. Bu yazılım, kuantum mekaniği, yapay zeka ve biraz da şans ile çayınızı mükemmel demler. (Gerçekte sadece print yapar ve bekler, ama şık duruyor.)

## Özellikler

- ✅ Gerçek zamanlı demleme simülasyonu
- ✅ Rastgele çay çeşitleri (siyah, yeşil, bitki, "kaybolmuş çorap çayı")
- ✅ Aşırı ciddi hata mesajları
- ✅ Dünya barışına katkı potansiyeli (henüz kanıtlanmamış)
- ✅ Patates içermez (kullanıcı talebi üzerine)

## Kurulum

```bash
pip install time random
python cay_demle.py
```

## Kullanım

Programı çalıştırın, çay isteyin, bekleyin, için. Basit.

## Bilimsel Temel

Bu yazılım, İstanbul Teknik Üniversitesi'nin hayali laboratuvarlarında 47 yıl süren araştırmalar sonucu geliştirilmiştir. Her demleme süresi, evrenin entropisi ile hesaplanır.
